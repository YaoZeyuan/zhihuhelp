# 知乎助手

知乎助手是一个本地桌面工具，用于把知乎回答、文章、想法、问题、收藏夹、专栏、话题和用户内容抓取到本地 SQLite 数据库，并生成 HTML / EPUB 电子书，方便个人离线阅读和整理。

项目由 [姚泽源](http://www.yaozeyuan.online/) 创作，采用 MIT 协议许可。

## 快速使用

1.  打开知乎助手。
2.  在“登录”页完成知乎登录。
3.  回到“任务管理”页，粘贴知乎链接并点击“识别链接”。
4.  选择输出格式和图片质量。
5.  点击“开始”。
6.  在“运行日志”页查看状态，并从输出历史打开结果。

完整说明见 [快速开始](doc/用户文档/快速开始.md)。

## 开发

环境要求：

| 项      | 版本 |
| ------- | ---- |
| Node.js | 24.x |
| pnpm    | 11.x |

安装依赖：

```shell
corepack enable
corepack prepare pnpm@11.5.0 --activate
pnpm install
```

常用命令：

```shell
pnpm build
pnpm watch
pnpm startgui
pnpm start
pnpm buildgui
pnpm zhihuhelp --help
```

完整开发说明见 [开发环境与命令](doc/开发文档/开发环境与命令.md)。

## 使用限制

知乎助手用于个人学习、整理和离线阅读。请遵守知乎内容版权、账号规则和相关法律法规，不要把生成的内容用于未获授权的分发或商业用途。
