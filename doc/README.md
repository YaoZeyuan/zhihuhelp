## 当前项目定位

知乎助手是一个本地桌面工具，用于把知乎回答、文章、想法、问题、收藏夹、专栏、话题和用户内容抓取到本地 SQLite 数据库，并生成 HTML / EPUB 电子书。

项目目前同时提供两种入口：

| 入口         | 面向对象         | 说明                                                         |
| ------------ | ---------------- | ------------------------------------------------------------ |
| Electron GUI | 普通用户         | 登录知乎、粘贴链接、配置输出、查看运行状态、浏览本地缓存数据 |
| CLI          | 开发者和高级用户 | 使用 `config.json` 执行初始化、抓取、生成和完整运行流程      |
