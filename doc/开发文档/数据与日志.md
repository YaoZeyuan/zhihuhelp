# 数据与日志

## 运行路径

路径由 `src/config/path.ts` 管理。

| 路径                        | 说明                   |
| --------------------------- | ---------------------- |
| `缓存文件`                  | 生成过程中的缓存根目录 |
| `缓存文件/imgPool`          | 图片缓存               |
| `缓存文件/html`             | HTML 生成缓存          |
| `缓存文件/epub`             | EPUB 生成缓存          |
| `知乎助手输出的电子书`      | 最终输出根目录         |
| `知乎助手输出的电子书/html` | HTML 输出              |
| `知乎助手输出的电子书/epub` | EPUB 输出              |
| `config.json`               | 当前任务配置           |
| `runtime.log`               | 人类可读运行日志       |
| `runtime.jsonl`             | 结构化运行日志         |

`RunContext` 会同步配置路径、数据库路径和输出路径，使 CLI 和 GUI 复用同一套 workflow。

## SQLite

数据库使用 `knex + sqlite3`。初始化 SQL 位于：

```text
src/infrastructure/sqlite/schema/init.sql
```

当前核心表：

| 表                    | 说明                         |
| --------------------- | ---------------------------- |
| `Answer`              | 回答原始数据和问题、作者索引 |
| `Article`             | 文章原始数据和专栏、作者索引 |
| `Pin`                 | 想法原始数据和作者索引       |
| `Author`              | 作者信息                     |
| `Column`              | 专栏信息                     |
| `Collection`          | 收藏夹信息                   |
| `Collection_Record`   | 收藏夹内回答、文章、想法关系 |
| `Topic`               | 话题信息                     |
| `Topic_Answer`        | 话题与回答关系               |
| `Activity`            | 用户行为记录                 |
| `Author_Ask_Question` | 用户提问过的问题关系         |

大部分表保留 `raw_json`，生成和数据浏览阶段会再解析知乎原始字段。

## 数据浏览模型

`src/model/summary.ts` 是 GUI 数据浏览的后端入口。

主要方法：

| 方法                    | 说明                                                     |
| ----------------------- | -------------------------------------------------------- |
| `asyncGetSummaryInfo()` | 返回回答、文章、想法、用户、问题、收藏夹、专栏、话题数量 |
| `asyncGetTabList()`     | 根据分类、分页和可选 parentId 返回列表                   |

当前展示模型把记录统一转换为：

| 字段                       | 说明                               |
| -------------------------- | ---------------------------------- |
| `recordKind`               | `answer`、`article`、`pin`、`meta` |
| `title/name`               | 展示标题                           |
| `description`              | 摘要                               |
| `contentHtml`              | 详情 HTML                          |
| `originContentHtml`        | 转发想法的原始内容                 |
| `sourceUrl`                | 原文链接                           |
| `author`                   | 作者信息                           |
| `voteupCount/commentCount` | 互动数                             |
| `createdAt/updatedAt`      | 时间戳                             |

## 日志

日志统一由 `src/library/logger.ts` 写入。

| 方法           | 输出                                       |
| -------------- | ------------------------------------------ |
| `Logger.log`   | 写入 `runtime.log` 并输出控制台            |
| `Logger.warn`  | 写入 `runtime.log` 并输出控制台 warning    |
| `Logger.event` | 写入 `runtime.jsonl`，同时生成一条文本日志 |

结构化日志常用字段：

| 字段         | 说明                                                                               |
| ------------ | ---------------------------------------------------------------------------------- |
| `triggerAt`  | 日志生成时间                                                                       |
| `runId`      | 一次任务运行 id                                                                    |
| `stage`      | `cli`、`config`、`init`、`fetch`、`persist`、`generate`、`render`、`output`、`ipc` |
| `status`     | `start`、`progress`、`success`、`skip`、`failure`                                  |
| `level`      | `debug`、`info`、`warn`、`error`                                                   |
| `message`    | 用户可读描述                                                                       |
| `durationMs` | 耗时                                                                               |
| `details`    | 阶段相关详情                                                                       |
| `error`      | 序列化错误                                                                         |

## 运行状态面板

前端运行日志页读取 `runtime.jsonl` 后，按最新 `runId` 构建阶段状态。

阶段顺序：

```text
配置 -> 初始化 -> 抓取 -> 生成 -> 输出
```

规则：

1.  只使用最新一次 `runId` 的事件，避免历史任务污染当前状态。
2.  未执行阶段保持灰色。
3.  当前阶段显示运行中。
4.  只有阶段完成事件或后续阶段开始后，才把阶段显示为成功。
5.  失败阶段显示错误，后续阶段保持等待。

## 输出历史

输出历史由 `get-output-history` 从 `runtime.jsonl` 构建。它会筛选带输出路径的成功事件，去重后按日志出现顺序倒序返回，最新输出在最前。

前端也会按 `createdAt` 做倒序兜底排序。

## 诊断导出

`export-diagnostic-info` 会在输出目录下创建：

```text
知乎助手输出的电子书/diagnostics/diagnostic-<timestamp>.json
```

内容包括：

1.  应用版本、Electron、Node、平台。
2.  路径信息。
3.  数据库摘要。
4.  脱敏任务配置。
5.  输出历史。
6.  最近文本日志。
7.  最近结构化日志。
