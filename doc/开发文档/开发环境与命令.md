# 开发环境与命令

## 环境要求

| 项       | 要求                             |
| -------- | -------------------------------- |
| Node.js  | 24.x                             |
| pnpm     | 11.x                             |
| Electron | 23.2.0                           |
| 前端构建 | Vite 4 + React 18 + Ant Design 5 |
| 后端编译 | Babel 编译 TypeScript 到 `dist`  |

仓库根目录和 `client` 都声明了 `packageManager: pnpm@11.5.0`。建议通过 Corepack 固定 pnpm 版本。

## 初次安装

```shell
corepack enable
corepack prepare pnpm@11.5.0 --activate
pnpm install
```

Windows 上如遇 `sqlite3`、`sharp` 等原生依赖安装失败，优先确认安装了 Visual Studio 2022 C++ 构建工具和 Python 3。

## 常用命令

| 命令                                           | 说明                                                |
| ---------------------------------------------- | --------------------------------------------------- |
| `pnpm build`                                   | 编译根项目 `src` 到 `dist`                          |
| `pnpm watch`                                   | 监听根项目源码并持续编译                            |
| `pnpm startgui`                                | 启动前端 Vite 服务，默认端口 8080                   |
| `pnpm start`                                   | 调试模式启动 Electron，加载 `http://localhost:8080` |
| `pnpm buildgui`                                | 构建前端并复制到 `dist/client`                      |
| `pnpm pack`                                    | 构建源码和前端，生成未打包目录                      |
| `pnpm dist`                                    | 构建源码和前端，并调用 electron-builder 生成安装包  |
| `pnpm zhihuhelp --help`                        | 查看 CLI 帮助                                       |
| `pnpm zhihuhelp init --config config.json`     | 初始化目录和数据库                                  |
| `pnpm zhihuhelp fetch --config config.json`    | 抓取数据并入库                                      |
| `pnpm zhihuhelp generate --config config.json` | 从数据库生成 HTML/EPUB                              |
| `pnpm zhihuhelp run --config config.json`      | 执行完整链路                                        |

## GUI 调试流程

建议开三个终端：

```shell
pnpm watch
pnpm startgui
pnpm start
```

调试模式下：

1.  Electron 主窗口加载 Vite 页面。
2.  主窗口默认打开 DevTools。
3.  `js-rpc` 子窗口在 debug 模式下可见，用于知乎签名相关能力。

## CLI 调试流程

1.  执行 `pnpm build` 或保持 `pnpm watch`。
2.  准备 `config.json`，可以参考 `demo.config.json`。
3.  执行 `pnpm zhihuhelp run --config config.json`。
4.  查看 `runtime.log` 和 `runtime.jsonl`。
5.  查看输出目录 `知乎助手输出的电子书`。

## 类型检查和构建现状

当前可稳定执行：

```shell
cd client
pnpm exec tsc --noEmit
pnpm build
```

根目录 `pnpm exec tsc --noEmit` 当前会命中历史 JS 文件的隐式 `any` 和 DOM 类型问题，主要在：

1.  `src/preload.js`
2.  `src/public/js-rpc/preload.js`
3.  `src/public/js-rpc/renderer.js`

这属于历史遗留问题。修改 TypeScript 文件时，仍应尽量保证新增 TS 代码不引入新的类型错误。
