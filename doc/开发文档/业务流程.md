# 业务流程

## 用户侧主流程

```mermaid
flowchart TD
  A["打开 GUI"] --> B["登录知乎"]
  B --> C["粘贴知乎链接"]
  C --> D["识别任务类型和 id"]
  D --> E["选择输出格式和图片质量"]
  E --> F["点击开始"]
  F --> G["查看运行状态"]
  G --> H["打开 HTML/EPUB 输出"]
```

## GUI 启动任务流程

```mermaid
sequenceDiagram
  participant UI as React 前端
  participant Main as Electron 主进程
  participant Session as Electron Session
  participant Config as config.json
  participant Workflow as RunTaskWorkflow
  participant Output as 输出目录

  UI->>Main: start-customer-task(config)
  Main->>Main: 检查运行锁 isRunning
  Main->>Session: 读取知乎 cookie
  Main->>Config: 写入任务配置和 cookie
  Main->>Workflow: run({ configPath })
  Workflow->>Workflow: init
  Workflow->>Workflow: fetch
  Workflow->>Workflow: generate
  Workflow->>Output: 输出 HTML/EPUB
  Main->>UI: 返回 success 或抛出错误
```

## CLI 完整流程

```text
pnpm build
pnpm zhihuhelp run --config config.json
```

`run` 会顺序执行：

1.  创建 `RunContext`，写入 `runId`，同步路径配置。
2.  检查并读取任务配置。
3.  初始化目录和数据库。
4.  抓取知乎数据并写入 SQLite。
5.  从 SQLite 读取内容并生成 HTML / EPUB。
6.  写入运行日志和输出结果记录。

## 抓取流程

```mermaid
flowchart TD
  A["TaskConfig.tasks"] --> B["按任务类型合并 id"]
  B --> C["选择 BatchFetch 实现"]
  C --> D["请求知乎 single API"]
  D --> E["写入 Model / SQLite"]
  C --> F["必要时扩展子任务"]
  F --> D
```

关键实现：

1.  `FetchWorkflow.execute` 接收旧结构任务配置。
2.  `mergeTaskList` 将同类型任务合并，跳过 `skipFetch` 的任务。
3.  `createBatchFetcher` 根据任务类型选择 `src/api/batch/*`。
4.  batch 层请求 `src/api/single/*` 并调用 `src/model/*` 入库。
5.  过程通过 `Logger.event` 写入结构化日志。

## 生成流程

```mermaid
flowchart TD
  A["读取 TaskConfig.generate"] --> B["从 DB 组装 Unit"]
  B --> C["按生成模式合并或独立输出"]
  C --> D["排序"]
  D --> E["自动分卷"]
  E --> F["渲染 HTML 页面"]
  F --> G["生成单页 HTML"]
  F --> H["处理图片和静态资源"]
  H --> I["生成 EPUB"]
  G --> J["复制到输出目录"]
  I --> J
```

核心概念：

| 概念 | 当前实现 | 说明 |
| --- | --- | --- |
| Page | `Page_Question`、`Page_Article`、`Page_Pin` | 电子书内容页 |
| Unit | `Unit_用户`、`Unit_收藏夹`、`Unit_话题`、`Unit_专栏`、`Unit_混合类型` | 一组内容页和信息页 |
| Ebook_Column | `Ebook_Column` | 一本或一卷电子书 |
| HtmlRender | `html_render` | React 模板渲染 HTML |
| EpubGenerator | `epub_generator.ts` | 资源处理、HTML/EPUB 输出 |

## 数据浏览流程

```mermaid
sequenceDiagram
  participant UI as 数据浏览页
  participant Main as Electron IPC
  participant Summary as MSummary
  participant DB as SQLite

  UI->>Main: get-db-summary-info
  Main->>Summary: asyncGetSummaryInfo()
  Summary->>DB: count
  UI->>Main: get-db-record-list(type,pageNo,pageSize,parentId)
  Main->>Summary: asyncGetTabList(...)
  Summary->>DB: select records
  Main->>UI: recordList + total
```

数据浏览的核心在 `src/model/summary.ts`。它把数据库记录转换为前端可展示的摘要、详情 HTML、作者信息和统计字段。
