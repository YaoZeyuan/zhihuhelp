# 问题 11：文档站下载入口

## 需求

1. 文档站首页运行时请求同源 `/api/zhihuhelp/version`，读取最新版本号以及 Windows、macOS 的实际下载地址。
2. 下载区域位于首页首屏主要位置，展示当前最新版本号和分平台下载按钮；不再使用跳转 GitHub Releases 的“下载最新版本”按钮。
3. 下载是首页首要操作，用户指南和开发文档降为次级入口。
4. 接口加载期间展示加载状态；响应无效或请求失败时展示错误和重试按钮，不使用可能过期的下载地址兜底。
5. 从首页 Hero 移除当前宣传图，保留品牌资源供 Open Graph 等其他场景使用。
6. VitePress 本地开发服务器将 `/api/**` 只读映射到仓库根目录的 `api/**`，便于直接验证版本接口；生产构建仍由现有脚本复制公开 API。
7. 首页下载区域使用 Vue 单文件组件和声明式模板实现，页面结构与样式类名应可直接编辑，不使用嵌套 `h()` 调用描述整块页面。

## 验收

- 首页首屏可快速看到最新版本及 Windows、macOS 下载按钮。
- 两个平台按钮分别使用接口 `detail.windows.url` 和 `detail.mac.url`。
- 接口异常不会产生无地址按钮，用户可以手动重试。
- 文档站构建与公开路由/API 校验通过。
- 本地 `pnpm docs:dev` 下 `/api/zhihuhelp/version` 与根目录源文件内容一致，目录穿越请求不可访问仓库其他文件。
