### 2. JSONL 日志边界

```text
triggerAt / runId / eventCode / source / stage / status / level /
message / durationMs / details / error
```

### 3. 测试分层与 Cookie

建议把测试拆成四层，而不是都称为单元测试：

| 层级             | 默认是否联网 | 目标                                                            |
| ---------------- | ------------ | --------------------------------------------------------------- |
| 单元测试         | 否           | 配置转换、URL 识别、任务合并、排序/分卷、日志序列化等纯逻辑     |
| 前端组件测试     | 否           | 任务表单、日志状态、数据浏览等关键交互，IPC 使用 mock           |
| 本地集成测试     | 否           | Workflow + 临时 SQLite + 固定 fixture，验证初始化、持久化和生成 |
| 知乎在线冒烟测试 | 是，显式启用 | 检查 Cookie、最小真实请求和可选的最小抓取链路                   |

默认 `pnpm test` 只运行前三类、无需 Cookie；`pnpm test:online` 才运行真实知乎请求，避免日常测试不稳定或误触发风控。
