# 功能说明

## 支持的任务类型

当前可识别并抓取的知乎内容包括：

| 类型             | 常见链接                                                          |
| ---------------- | ----------------------------------------------------------------- |
| 用户的所有回答   | `https://www.zhihu.com/people/<url_token>`                        |
| 用户发布的文章   | 用户主页文章列表                                                  |
| 用户发布的想法   | 用户主页想法列表                                                  |
| 用户提问过的问题 | 用户主页提问列表                                                  |
| 用户赞同过的回答 | 用户主页动态 / 活动记录                                           |
| 用户赞同过的文章 | 用户主页动态 / 活动记录                                           |
| 用户关注过的问题 | 用户主页关注问题                                                  |
| 问题             | `https://www.zhihu.com/question/<id>`                             |
| 回答             | `https://www.zhihu.com/question/<question_id>/answer/<answer_id>` |
| 文章             | `https://zhuanlan.zhihu.com/p/<id>`                               |
| 想法             | `https://www.zhihu.com/pin/<id>`                                  |
| 收藏夹           | `https://www.zhihu.com/collection/<id>`                           |
| 专栏             | `https://zhuanlan.zhihu.com/<id>`                                 |
| 话题             | `https://www.zhihu.com/topic/<id>`                                |

部分用户相关任务依赖知乎接口权限和账号状态。如果知乎限制接口访问，可能需要重新登录或缩小任务范围。

## 输出格式

每次任务固定生成以下三种格式，GUI 不提供格式选择器。当前 schema 中仍保留 `outputFormats` 字段用于兼容配置文件，但读取旧的单格式或双格式值时会规范化为完整三格式，不能据此关闭某一种输出。

| 格式     | 说明                                                       |
| -------- | ---------------------------------------------------------- |
| HTML     | 适合在浏览器中阅读、检查内容、打印为 PDF                   |
| Markdown | 适合纯文本归档、全文检索以及在支持 GFM 的工具中继续编辑    |
| EPUB     | 适合导入电子书阅读器                                       |

HTML 更容易确认抓取内容是否完整，也方便排查 EPUB 阅读器兼容问题。Markdown 会转换每本书的全部多文件 HTML 页面和单文件 HTML，而不是只转换目录页或正文合集。

单文件 HTML 自带目录：桌面浏览器中显示可折叠侧栏，窄屏设备中目录位于正文顶部，目录项可直接跳转到信息页或内容页。

每本书的 Markdown 目录结构如下，`<安全书名>` 使用与 HTML/EPUB 相同的文件名清理规则：

```text
知乎助手输出的电子书/<安全书名>/
  html/
  markdown/
    html/
      <每个多文件 HTML 对应页面>.md
    单文件版/
      <单文件 HTML 对应页面>.md
  epub/
    <安全书名>.epub
```

转换后的内部页面链接会指向实际生成的 `.md` 文件。某一页无法由 Pandoc 转换时，会保存为同目录的 `<名称>.pandoc-failed.md`，内容是已清理的 HTML，其他 Markdown 页面也会改为链接到该回退文件。回退文件可用时任务只记录警告，不会仅因一次转换失败变成“部分成功”；只有结果文件确实无法写入等输出故障，才会按已有结果数量进入部分成功或失败。

## 图片质量

| 选项 | 说明                               |
| ---- | ---------------------------------- |
| 高清 | 默认选项；HTML/EPUB 使用本地高清图，Markdown 保留替代文本和远程 URL |
| 原图 | HTML/EPUB 尽量使用本地原图，Markdown 保留替代文本和原始远程 URL     |
| 无图 | 三种输出都移除正文图片，速度更快，输出更小                         |

HTML/EPUB 图片会缓存在本地 `缓存文件/imgPool`。Markdown 不复制图片文件；选择高清或原图时直接引用对应的远程 URL，因此离线查看 Markdown 图片仍需要网络。生成次数很多时，缓存目录可能变大。

## 生成模式

高级配置中可以调整生成模式：

| 模式       | 说明                                 |
| ---------- | ------------------------------------ |
| 独立成书   | 每个任务尽量独立输出一本书           |
| 按任务合并 | 多个任务合并成一本书，按任务拆分章节 |
| 打乱合并   | 多个任务内容混合后排序输出           |

第一次使用建议保持默认模式。

## 排序规则

高级配置中可以添加排序规则。支持的维度包括：

| 排序项       | 说明                           |
| ------------ | ------------------------------ |
| 不排序       | 保留默认顺序                   |
| 创建时间     | 按回答、文章或想法创建时间排序 |
| 更新时间     | 按最后更新时间排序             |
| 赞同数       | 按赞同或喜欢数量排序           |
| 评论数       | 按评论数量排序                 |
| 记录加入时间 | 对收藏夹、活动类数据有意义     |

排序方向支持升序和降序。多个排序规则会按列表顺序依次应用。

## 自动分卷

自动分卷用于避免单本电子书过大。默认每本最多容纳 10000 条回答、文章或想法。超过限制后会输出多卷。
