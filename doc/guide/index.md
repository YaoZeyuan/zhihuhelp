## 使用前说明

知乎助手用于个人学习、整理和离线阅读。请遵守知乎内容版权、账号规则和相关法律法规，不要把生成的内容用于未获授权的分发或商业用途。

## 当前 GUI 页面

| 页面     | 用途                                                           |
| -------- | -------------------------------------------------------------- |
| 任务管理 | 登录状态检测、粘贴知乎链接、识别任务、配置生成方式并启动       |
| 运行日志 | 查看阶段状态、本会话错误、书籍级输出历史，导出诊断信息         |
| 数据浏览 | 按回答、文章、想法、问题、用户、收藏夹、专栏、话题浏览本地缓存 |
| 登录     | 使用内置 webview 登录知乎                                      |
| 调试面板 | 默认隐藏，仅开发者模式使用                                     |
