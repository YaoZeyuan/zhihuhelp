# 数据浏览与输出结果

## 本地缓存数据

知乎助手会先把抓取结果写入本地 SQLite 数据库，再从数据库生成 HTML 和 EPUB。这样做有两个好处：

1.  已抓取的数据可以复用，后续可以跳过抓取直接重新生成。
2.  可以在“数据浏览”页确认本地已经缓存了哪些内容。

## 数据浏览页

数据浏览页支持按类别查看本地数据：

| 类别   | 说明                     |
| ------ | ------------------------ |
| 回答   | 已缓存的知乎回答         |
| 文章   | 已缓存的知乎文章         |
| 想法   | 已缓存的知乎想法         |
| 问题   | 已缓存回答所属的问题索引 |
| 用户   | 已缓存作者索引           |
| 收藏夹 | 已缓存收藏夹索引         |
| 专栏   | 已缓存专栏索引           |
| 话题   | 已缓存话题索引           |

点击回答、文章、想法分类后，页面会先展示摘要列表。点击某条摘要后进入详情页，可查看接近输出 HTML 的内容展示，并使用“上一个 / 下一个”连续浏览。

点击问题、用户、收藏夹、专栏或话题等索引类记录时，可以进入该分类下关联的回答、文章或想法列表。

## 输出历史

“运行日志”页包含输出历史。记录按最新输出倒序排列，最后生成的记录显示在最前。

每条历史记录可能包含：

| 按钮         | 用途                 |
| ------------ | -------------------- |
| 打开 HTML    | 打开或定位 HTML 输出 |
| 打开 EPUB    | 打开或定位 EPUB 输出 |
| 打开输出目录 | 打开本次输出所在目录 |

如果某条记录没有对应格式，说明本次任务没有生成该格式，或日志中没有记录到对应路径。

## 输出目录

默认输出目录在项目运行根目录下：

```text
知乎助手输出的电子书/
  html/
  epub/
```

缓存目录在：

```text
缓存文件/
  imgPool/
  html/
  epub/
```

`知乎助手输出的电子书` 是最终结果；`缓存文件` 是生成过程使用的临时和缓存资源。一般只需要打开输出目录。

## 诊断信息

运行日志页提供“导出诊断信息”。诊断文件会保存到输出目录下的 `diagnostics` 文件夹，内容包括：

1.  应用版本和运行环境。
2.  常用路径。
3.  数据库摘要。
4.  脱敏后的任务配置。
5.  输出历史。
6.  最近运行日志和结构化日志。

反馈问题时，优先附带诊断文件。
