# 数据浏览与输出结果

## 本地缓存数据

知乎助手会先把抓取结果写入本地 SQLite 数据库，再从数据库固定生成 HTML、Markdown 与 EPUB。这样做有两个好处：

1.  已抓取的数据可以复用，后续可以跳过抓取直接重新生成。
2.  可以在“数据浏览”页确认本地已经缓存了哪些内容。

## 数据浏览页

数据浏览页支持按类别查看本地数据：

| 类别   | 说明                     |
| ------ | ------------------------ |
| 回答   | 已缓存的知乎回答         |
| 文章   | 已缓存的知乎文章         |
| 想法   | 已缓存的知乎想法         |
| 问题   | 已缓存回答所属的问题索引 |
| 用户   | 已缓存作者索引           |
| 收藏夹 | 已缓存收藏夹索引         |
| 专栏   | 已缓存专栏索引           |
| 话题   | 已缓存话题索引           |

点击回答、文章、想法分类后，页面会先展示摘要列表。点击某条摘要后进入详情页，可查看接近输出 HTML 的内容展示，并使用“上一个 / 下一个”连续浏览。

点击问题、用户、收藏夹、专栏或话题等索引类记录时，可以进入该分类下关联的回答、文章或想法列表。

## 输出历史

“运行日志”页包含输出历史。记录按最新输出倒序排列，最后生成的记录显示在最前。

每条历史记录可能包含：

| 按钮          | 用途                     |
| ------------- | ------------------------ |
| 打开 HTML     | 打开或定位 HTML 输出     |
| 打开 Markdown | 打开对应书的 Markdown 目录 |
| 打开 EPUB     | 打开或定位 EPUB 输出     |
| 打开输出目录  | 打开本次输出所在目录     |

正常的新记录会包含三种格式。若某条记录缺少 Markdown 等入口，通常表示该输出在写入前失败，或该记录来自升级前的旧日志。输出历史只扫描最近五个自然日的后端 JSONL；第六日清理旧日志后，历史入口同步消失，但不会删除结果目录中的文件。

## 输出目录

默认输出目录在项目运行根目录下：

```text
知乎助手输出的电子书/
  html/
  markdown/
  epub/
```

缓存目录在：

```text
缓存文件/
  imgPool/
  html/
  markdown/
  epub/
```

`知乎助手输出的电子书` 是最终结果；`缓存文件` 是生成过程使用的临时和缓存资源。一般只需要打开输出目录。

每一本书在 `markdown` 下使用安全化书名建目录，并镜像该书的全部 HTML 来源：

```text
markdown/<安全书名>/
  html/*.md
  单文件版/*.md
```

Markdown 中的页面间链接会改写为 `.md`。图片质量为“无图”时图片标签会删除；“高清”或“原图”时保留替代文本并指向远程 URL，不复制 HTML/EPUB 使用的本地图片。Pandoc 单页转换失败会生成 `.pandoc-failed.md` 回退文件；回退写入成功只显示警告，真正的文件写入故障才可能令任务部分成功或失败。

## 诊断信息

运行日志页提供“导出诊断信息”。诊断文件会保存到输出目录下的 `diagnostics` 文件夹，内容包括：

1.  应用版本和运行环境。
2.  常用路径。
3.  数据库摘要。
4.  脱敏后的任务配置。
5.  输出历史。
6.  最近运行日志和结构化日志。

反馈问题时，优先附带诊断文件。
