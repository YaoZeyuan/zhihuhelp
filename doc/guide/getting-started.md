# 快速开始

## 1. 打开软件并登录

1.  打开知乎助手。
2.  进入“登录”页。
3.  在内置知乎页面中完成登录。
4.  回到“任务管理”页，点击“重新检测”确认登录状态。

如果状态显示“未登录或登录已失效”，请重新进入登录页登录，或使用账户菜单中的注销后重新登录。

## 2. 粘贴知乎链接

在“任务管理”页的输入框中粘贴知乎链接，每行一个。支持单条和多条链接。

示例：

```text
https://www.zhihu.com/question/26784045
https://www.zhihu.com/question/26784045/answer/178802510
https://zhuanlan.zhihu.com/p/58653502
https://www.zhihu.com/pin/1013109294408986624
```

点击“识别链接”后，页面会显示已识别的有效任务数量。如果有链接无法识别，页面会提示是哪一条需要检查。

## 3. 设置生成方式

常用设置：

| 设置     | 建议                                                 |
| -------- | ---------------------------------------------------- |
| 电子书名 | 默认开启自动生成，通常不需要手动填写                 |
| 图片质量 | 默认选择高清；想减小体积可选无图；原图会显著增大文件 |

GUI 不提供输出格式选择。每次任务都会固定生成 HTML、Markdown 与 EPUB，旧配置中只保存了部分格式时也会自动按三种格式执行。

高级配置默认折叠，包含生成模式、排序、自动分卷和备注。第一次使用可以保持默认。

## 4. 开始生成

点击“开始”。程序会先检查登录状态，再启动任务，并自动切换到“运行日志”页。

运行状态面板会展示当前阶段：

| 阶段   | 含义                               |
| ------ | ---------------------------------- |
| 配置   | 读取并保存任务配置                 |
| 初始化 | 创建缓存目录、输出目录和数据库表   |
| 抓取   | 请求知乎接口并写入本地数据库       |
| 生成   | 从数据库读取内容并生成 HTML、Markdown 与 EPUB |
| 输出   | 完成输出并记录结果                 |

未执行的阶段会保持灰色；正在执行的阶段显示运行中；失败时会显示最近错误。

## 5. 打开结果

任务完成后，可以在以下位置查看结果：

| 位置                            | 内容                                               |
| ------------------------------- | -------------------------------------------------- |
| `知乎助手输出的电子书/html`     | 多文件和单文件 HTML                                |
| `知乎助手输出的电子书/markdown` | 与每本书全部 HTML 页面对应的 Markdown              |
| `知乎助手输出的电子书/epub`     | EPUB 电子书                                        |

也可以在“运行日志”的“输出历史”中直接打开 HTML、Markdown、EPUB 或总输出目录。历史只覆盖最近五个自然日；旧日志被清理后，对应入口也会消失，但已经生成的文件不会因此删除。
