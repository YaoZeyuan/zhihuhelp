# 常见问题

## 登录状态检测失败

可能原因：

1.  内置登录页没有完成知乎登录。
2.  登录态过期。
3.  知乎接口临时限制访问。

处理方式：

1.  进入“登录”页重新登录。
2.  回到“任务管理”页点击“重新检测”。
3.  如果仍失败，使用账户菜单注销后重新登录。

## 粘贴链接后无法识别

请检查：

1.  是否是知乎链接。
2.  链接是否包含问题、回答、文章、想法、收藏夹、专栏、话题或用户信息。
3.  是否一行一个链接。

如果页面提示某一条需要检查，可以先删除该条，确认其他任务可以正常执行。

## 抓取很慢或卡住

知乎助手会对请求做节流保护，避免短时间内频繁请求知乎接口。大量任务、图片较多、收藏夹较大时都会变慢。

建议：

1.  先用少量链接验证流程。
2.  图片质量选择“高清”或“无图”。
3.  大收藏夹或大用户主页分批处理。
4.  查看“运行日志”中的当前阶段和最近错误。

## 生成 EPUB 很慢

生成 EPUB 需要处理 HTML、图片、目录和压缩包。内容越多、图片越多，耗时越长。

建议：

1.  保留 HTML 输出，先确认内容正常。
2.  过大的任务开启自动分卷。
3.  图片质量不要轻易选择原图。

## 输出目录没有看到文件

请确认：

1.  任务是否执行到“输出”阶段。
2.  输出格式是否勾选了 HTML 或 EPUB。
3.  是否打开了正确的输出目录。
4.  运行日志中是否有失败提示。

可以在“运行日志”页查看输出历史，直接点击打开对应结果。

## 数据浏览只有数量或内容不完整

数据浏览展示的是本地 SQLite 中已有的数据。如果刚开始抓取，或者任务失败，可能只有部分索引或摘要。

建议：

1.  等任务完成后再刷新数据浏览。
2.  进入具体分类查看列表和详情。
3.  对问题、用户、收藏夹、专栏、话题等索引类内容，点击索引后再查看关联回答、文章和想法。

## 反馈问题时需要提供什么

建议提供：

1.  问题描述。
2.  触发问题的知乎链接。
3.  运行日志页导出的诊断信息。
4.  如果方便，附上截图。
